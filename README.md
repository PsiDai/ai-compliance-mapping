# AI Compliance Mapping

An open dataset that maps one control across the **EU AI Act**, **NIST AI RMF** and **ISO/IEC 42001**, with the evidence an auditor would ask for. In other words, an AI governance crosswalk built around the job people actually have: showing compliance.

**Status: being built now. Launch date to be confirmed.** Nothing here is a finished release yet.

Home page and progress: https://alchemy.consulting/ai-compliance-mapping

## What it will be

- One control, mapped to the matching requirements in each framework, so you do the work once and evidence it three ways.
- The evidence an auditor would ask for, listed against each control.
- Machine-readable data (JSON/CSV) plus a plain-English view.
- Versioned releases, with a change log of what moved and why.

## Important

This is a mapping aid. It supports compliance work and is indicative only. It is **not legal advice** and does not certify conformity with any framework. NIST AI RMF is voluntary; ISO/IEC 42001 is certifiable by an accredited body; the EU AI Act is law with its own timelines. Check requirements with a qualified adviser.
