# Contributing

Thanks for your interest.

- **Welcome now:** questions, ideas, corrections and real-world use cases, through Discussions or Issues.
- **Not yet:** pull requests. They are closed for now while the licence for the dataset is settled, so contributions can be accepted cleanly. This will be revisited before v1.
- **Using it in your organisation?** Open a "Commercial use enquiry" issue form, or book a conversation via https://alchemy.consulting/ai-compliance-mapping

This project is not legal advice. Please do not post confidential or client information in public issues.
